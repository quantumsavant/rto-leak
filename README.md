# RTO Leak

Free calculator for D2C brands: see how many lakhs RTO silently burns every year.

- 4 sliders → live annual RTO burn
- Shareable PNG card for founders
- UPI/Razorpay donation section (free forever, donations fuel the next tool)
- Pure client-side. No signup. No API.

Math: every RTO event ≈ ₹200–250 (forward + return shipping, per GoKwik). Monthly burn = orders × COD% × RTO% × ₹225.

Built with React + Vite + Tailwind.
